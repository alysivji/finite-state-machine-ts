# Examples

These examples mirror the documented state machines covered by the example test suite. They are the applied usage track for the docs site, not a separate source of truth.

Each page includes:

- a Mermaid state diagram
- a complete TypeScript example
- a short explanation of how the transition methods map to the diagram

Core sync and async transition semantics are covered separately by focused unit tests, so these pages stay small and example-oriented.
